# Contract Alignment

This repository is the **operator, creative OS, and metacognitive demonstration surface**. It is not an authority engine.

The sole semantic and authority source is [`cranium-kernel`](https://github.com/worthwyl2022-cloud/cranium-kernel). Browser state, resonance-field state, generated narrative, local reducers, and UI status are non-canonical. The OS may submit requests, display Kernel responses, and package diligence context; it must not grant authority, issue canonical receipts, mutate Kernel state directly, or represent a demo result as a live Kernel evaluation.

The acquisition posture is explicit: creative generation is advisory and provisional; only a real Kernel evaluation and durable commit can establish an authority outcome. Any offline or unavailable backend state must be labeled unavailable or non-authoritative rather than simulated.
